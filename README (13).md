## 📌 Project Overview
This project analyzes statistical distributions using Python.  
It loads dataset, checks basic information, and visualizes distribution using charts and Q-Q plot.

## 🎯 Objectives
- Load dataset using pandas
- Check basic dataset information
- Understand statistical distribution
- Plot Histogram
- Plot Boxplot
- Plot Q-Q Plot
- Check Normal Distribution

## 🛠 Tools & Libraries
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scipy

## ▶️ Steps Performed
1. Import libraries
2. Load dataset
3. View dataset using head()
4. Check dataset info()
5. Describe dataset
6. Plot histogram
7. Plot boxplot
8. Plot Q-Q plot
9. Interpret results

## 📊 Output
- Distribution Charts
- Outlier Detection
- Normality Check
