# Theory

## What is Statistical Distribution?
Statistical distribution shows how data values are spread across dataset.
It helps identify common values and rare values.

## Histogram
Histogram shows frequency of data values.
It helps understand shape of distribution.

## Box Plot
Box plot shows median, quartiles and outliers.
It helps detect extreme values.

## Q-Q Plot
Q-Q plot compares dataset with normal distribution.
If points follow straight line, data is normally distributed.

## Normal Distribution
Normal distribution is bell shaped curve.
Mean, median and mode are equal.

## Outliers
Outliers are extreme values different from rest of data.
Boxplot helps detect outliers.
